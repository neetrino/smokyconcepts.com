## Ադապտիվ արժեքներ — քննարկման համար

### ԲԴ կարգավորումներ (Neon)

1. **Connection limit** — Neon-ի համար խորհուրդ եմ տալիս 15–30 connections (serverless-ի համար 10–15):
   - Ո՞րն ենք դնում։

2. **statement_timeout** — Serverless-ի համար խորհուրդ եմ տալիս 10–15s, backend-ի համար 15–30s:
   - Ո՞րն ենք դնում։

3. **idle_in_transaction_session_timeout** — խորհուրդ եմ տալիս 10s–30s:
   - Ո՞րն ենք դնում։

4. **lock_timeout** — խորհուրդ եմ տալիս 5s–10s:
   - Ո՞րն ենք դնում։

### Անվտանգություն

1. **Rate limiting** — պետք է՞ ավելացնել API routes-ի համար:
   - Եթե այո — քանի՞ requests per minute/IP։

2. **CORS** — որ դոմեններ են թույլատրված:
   - Production դոմեն, localhost (dev)։

3. **Գաղտնաբառի հեշավորում** — փոխարինե՞լ bcryptjs-ը argon2-ով:
   - Առաջարկում եմ այո (ավելի անվտանգ)։

### Ֆայլերի պահոց

1. **Cloudflare R2** — պետք է՞ կարգավորել:
   - Եթե այո — տվեք R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_BUCKET_NAME։

### DevOps

1. **CI/CD** — պետք է՞ GitHub Actions:
   - Եթե այո — ինչպիսի՞ pipeline (build, test, deploy)։

2. **Error tracking** — պետք է՞ Sentry:
   - Եթե այո — տվեք SENTRY_DSN։

3. **Շրջակա միջավայրեր** — միայն prod, թե՞ dev + prod:
   - Խորհուրդ եմ տալիս dev + prod (Neon branches, Vercel env)։

4. **Դոմեն** — Vercel ավտո, թե՞ անհատական դոմեն:
   - Եթե անհատական — տվեք դոմենի անունը։
